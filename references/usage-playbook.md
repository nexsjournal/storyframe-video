# 使用手册：从一句话到成片

这是给“要用这支片子的人”看的，不是给剪辑师看的方法论。你不需要先学会写分镜；把下面几样东西给清楚，剩下的由 skill 推进。

## 1. 你最少要准备什么

| 项 | 是否必须 | 说明 |
|---|---|---|
| 一句话目标 | 必须 | 这条片子给谁看、发在哪、看完做什么 |
| 文案 | 推荐 | 有就按原文做；没有就由 skill 起草 |
| 音乐 | 推荐 | 有文件就用你的；没有就生成/代码合成 |
| 素材 | 看类型 | 产品链接/截图/录屏/Logo/字体/现场照片 |
| 必须出现的信息 | 必须 | 日期、城市、展位、URL、二维码、价格、免责声明 |
| 参考片 | 可选 | 说清“喜欢它的什么”，不要只说“这种感觉” |
| 限制 | 可选 | 版权、不能出现的人/品牌、deadline |

文件放在哪里都可以，给路径就行。skill 会把它们复制进工程，**不会改你的原文件**。

## 2. 三种常见起点

### A. 只有一句话

```text
用 storyframe-video-skill 做一条 30 秒产品宣传片，产品是「绘声绘色」。
```

skill 会先问你三组问题：要什么片、有没有文案、有没有音乐/素材。你逐条回答即可；不知道的直接说“没有/你定”。

### B. 已经有文案和音乐（最顺）

```text
用 storyframe-video-skill 做一条 30 秒 16:9 官网宣传片。
文案在 ./copy.md，音乐在 ./music.mp3（已授权商用）。
产品截图和 Logo 在 ./assets/。
必须出现：产品名、官网 URL、10 月 24 日发布会。
```

这是最推荐的起点。skill 会先核验文件、读文案、测音乐时长/BPM，再进入方向。

### C. 只有参考片

```text
用 storyframe-video-skill 做一条 20 秒活动预告。
参考这个片子的节奏和转场：<链接>；喜欢它“每 2 秒一个动作”，但不要抄画面和配色。
活动信息：……
```

skill 会拆参考片的 **结构 / 视觉 / 声音**，再给三个不同轴的方向，而不是直接复刻。

## 3. 正常流程：你会在什么时候看到什么

| 阶段 | skill 做什么 | 你要做什么 |
|---|---|---|
| Intake | 判断模式，问缺失的文案/音乐/素材 | 给路径、回答问题、确认假设 |
| Research | 核对产品事实、活动信息、歌词/原片 | 提供可公开的证据；确认哪些不能写 |
| **Gate A** | 一句话承诺 + 3 个方向 + 时长/画幅 | 选方向，或说“B 但换掉……”，别只说“高级一点” |
| Script | 写逐句文案/口播/歌词 | 确认必须保留的句子和不能改的词 |
| Storyboard | 分镜 + `plan.json` + animatic | 看时间、信息密度、首帧；按时间码提意见 |
| **Gate B** | 分镜/animatic 定稿 | 确认“时间对、信息清、首帧成立” |
| Build | 接真实素材、做动效/剪辑 | 补缺失素材；确认界面/数据是否可公开 |
| Sound | 音乐卡点、口播修复、音效、混音 | 确认音乐授权；听一遍人声是否清楚 |
| **Gate C** | 粗剪 | 静音看一遍、听一遍，按“画面/声音/字幕”分开提 |
| Final / **Gate D** | 导出、自动检查、人工检查 | 看最终 MP4、字幕、封面；确认 CTA/日期/价格 |
| Deliver | MP4 + SRT + 封面 + 工程 + QA | 收片；需要改版时从对应 Gate 回去 |

四个 Gate 是“停下来对齐”的点，不是形式。跳过 Gate A/B 直接渲染，通常会在最后返工。

## 4. 文案怎么给

- 直接粘贴、给 `.md/.docx/.txt` 路径、或给在线文档链接都可以。
- 不用先润色。标出“必须保留”的句子、产品名、slogan、法律措辞。
- skill 只做删减、口语化、调顺序；**改动会记在 `SCRIPT.md`**，不会悄悄重写你的卖点。
- 如果你只有几个卖点，没有成稿，直接说“没有文案，帮我写”，并给必须出现的点。

## 5. 音乐怎么给

- 给文件路径最稳：`./music.mp3`、`./audio/song.wav`。
- 知道 BPM、段落（intro/verse/chorus）、是否可商用、是否要署名，一起说；不知道 BPM 也没关系，skill 会测/分析。
- 有歌词就给歌词；有原唱/配音就给音频和 transcript。
- **有音乐文件时，skill 会以它为时间基准卡点，不会重新生成一首替换它。**
- 没有音乐时，skill 会明确告诉你将使用“生成音乐”或“代码合成”，确认后再做。

## 6. 素材怎么给

推荐一个文件夹：

```text
my-video/
  brief.md          # 一句话目标、平台、时长、必须出现
  copy.md           # 文案/口播稿（可选）
  music.mp3         # 音乐（可选）
  assets/
    logo.svg
    product-home.png
    demo.mov
    poster.jpg
```

- 截图尽量给原始分辨率，不要给微信压缩图。
- Logo 优先 SVG 或透明 PNG；字体要给授权文件/来源。
- 产品演示给录屏比给几张截图更好；录屏要包含真实操作和结果。
- 参考片给链接，并写一句“喜欢它的结构/视觉/声音中的哪一层”。

## 7. 每个 Gate 怎么给反馈

**Gate A（方向）**

- 好反馈：`选 B。保留纸感，但把强调色从红换成品牌绿；开头不要用大字，直接用产品结果。`
- 差反馈：`再高级一点。`（无法执行）

**Gate B（分镜/animatic）**

- 按时间码说：`0–3s 信息太满，删掉第二行；7.5s 的转场太快，留 0.5s。`
- 重点看：时间是否对、每镜是否有动作、首帧是否能当缩略图、claims 是否有来源。

**Gate C（粗剪）**

- 分开说：画面问题 / 声音问题 / 字幕问题。
- 先静音看一遍，再听一遍；不要边看边随机改。

**Gate D（终版）**

- 看 MP4、SRT、封面三件套；确认日期、价格、CTA、二维码停留时间。
- 自动检查通过不等于好看；最终仍需人看、人听、手机看。

## 8. 常见误区

- **先要风格，后给素材**：方向会飘，最后只能套模板。
- **给盗版音乐/字体**：不能进成片；要么换，要么取得授权。
- **分镜定了又大改文案**：时间轴会全部重排，至少多一轮。
- **不看 animatic 直接渲染**：渲染 30 秒可能只要几分钟，返工改结构要几小时。
- **只说“随便/你定”**：可以做，但默认值会在 `BRIEF.md` 里标成“假设”，后面改要加钱/加时间。
- **期待一次就完美**：正常是 2–3 轮反馈；第一轮先把结构和信息定对，再抠细节。

## 9. 最小启动模板（复制即用）

```text
用 storyframe-video-skill 做一条视频。

- 用途/平台：官网首页 / 抖音 / 展会大屏
- 画幅/时长：16:9 / 30 秒
- 文案：见 ./copy.md（必须保留：……；不能改：……）
- 音乐：./music.mp3（可商用；BPM 124；如果不能用请告诉我）
- 素材：./assets/（logo.svg、首页.png、demo.mov）
- 必须出现：产品名、URL、日期、二维码
- 不要出现：……
- 参考：<链接>，喜欢它的节奏，不要抄画面
- 截止：……
```

只有 1 分钟时，至少给这四行：

```text
做一条 <平台> <时长> 的 <类型>，产品/主题是 <……>。
文案在 <路径>（没有就说没有）。
音乐在 <路径>（没有就说没有）。
必须出现 <……>，不要出现 <……>。
```
