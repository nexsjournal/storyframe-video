# 影片方向

方向不是“风格参考”，而是一套 **从主题推导出来的视觉/叙事规则**。没有方向的片子，最后一定会变成模板拼贴。

## 1. 拆参考：三层，不是一层

拿到参考视频，不要只说“我喜欢这个感觉”。拆：

### 结构层
- 时长、镜头数、平均镜头长度、最快/最慢段。
- 段落：hook、铺垫、转折、高潮、结尾各占多少秒。
- 信息释放顺序：先给结果还是先给过程？先给问题还是先给答案？
- 转场类型与频率：硬切、闪白、match cut、whip、扫描、材质转场。

### 视觉层
- 色彩：主色/辅色/强调色；明暗比例；是否有纸张/噪点/扫描线/辉光。
- 字体：字重、字距、大小对比；中文/英文如何搭配；标题是否被拆成单词/单字。
- 构图：中心/偏心；留白比例；网格；是否有 3D 相机/景深。
- 材质：纸、墨、金属、玻璃、LED、手绘、像素。
- 运动：推拉、旋转、跟随、弹跳、逐字、遮罩、变形。

### 声音层
- 音乐类型/BPM/能量曲线；哪里留白；哪里 impact。
- 音效：哪些动作有声音；声音是写实还是风格化。
- 人声：是否有口播/演唱；语气；混音位置。

拆完写一句：“我借它的 **结构**（前 3 秒给结果、每 8 秒一个转折），不借它的 **配色**。”

## 2. 三个方向：必须在不同轴上

不要给“红色版/蓝色版/绿色版”。三个方向至少在两个轴上不同：

| 轴 | 选项 A | 选项 B | 选项 C |
|---|---|---|---|
| 叙事 | 问题→解决 | 一天/流程 | 对比/前后 |
| 视觉隐喻 | 纸与墨 | UI 电影 | 数据仪器 |
| 镜头材质 | 手作定格 | 3D 相机 | 平面排版 |
| 声音 | 轻电子 | 环境+口播 | 打击/节奏 |

每个方向写：

```md
### 方向 A：纸上的乐器
- 一句话：产品界面是一张会发声的纸，颜色落下去就变成乐器。
- 3 个专属手法：纸纹/墨线、颜色=音色、扫描线点亮。
- 参考：...（只借结构/材质，不抄镜头）
- 风险：纸感容易显旧；需要高对比强调色。
- 适合：手绘/创作/教育类产品。
```

### 选择标准
1. **产品真相**：这个方向是否放大了产品最独特的一点？
2. **受众**：目标观众是否一眼能懂？
3. **可执行**：现有素材/时间/技术能否做到 80 分以上？
4. **差异化**：是否和竞品/上一支片子明显不同？
5. **可扩展**：能否撑满 30–60 秒，而不是只有一张好海报？

## 3. 专属手法：3–5 个“因为…所以…”

每个手法都要能追溯：

- 因为产品把 **线条** 变成旋律，所以副歌让线条变成声波/五线谱/3D 纸带。
- 因为产品用 **九种颜色** 代表九种乐器，所以每次落色都有独立音色和色块运动。
- 因为产品是 **扫描画作** 得到音乐，所以转场用扫描线/读取头/像素点亮。
- 因为课程是 **步骤式**，所以画面用编号、进度、放大镜，而不是装饰粒子。
- 因为活动是 **线下展会**，所以结尾用展位号/地图/二维码，不用抽象口号。

写进 `DIRECTION.md` 的 `Motifs` 段；每个镜头至少服务一个 motif。

## 4. 视觉规范：写成数字

`DIRECTION.md` 必须包含：

```md
## Visual system
- Canvas: 1920×1080, 30fps; safe area 5%.
- Palette: bg #F6F1E6; ink #17141A; accent #F2416B; support #D84B4B #E5B73B #42866A #4A7BBD #8764AD.
- Type: display [font/weight/size]; body [font/weight/size]; caption [size/line-height].
- Grid: 12 columns, margin 96px, gutter 24px.
- Texture: paper grain 4–8% opacity; vignette 8%; no glossy bevel.
- Motion: camera push 1.00→1.06 over 2s; type stagger 35ms; blur-in 14px→0; no bounce except playful beat.
- Transitions: hard cut on beat; flash 2 frames; scan wipe 6 frames; no random glitch.
-禁止: 科技蓝渐变、六边形粒子、无意义 HUD、所有元素同一种入场。
```

数字不是束缚，是让不同镜头看起来像同一支片子。

## 5. 反 PPT 规则

- 每个镜头至少一个：**相机运动 / 字体变形 / 材质转场 / 主体动作 / 声音驱动切点**。
- 连续纯静态全屏卡片不超过 2 个；静态只允许出现在结尾海报/二维码。
- 不要“标题 + 三行 bullet”重复；把 bullet 变成图解、对比、演示、数字动画。
- 同一支片子里，不要所有标题都用同一种入场；至少 2 种字体运动、2 种转场。
- 如果一段 5 秒内没有任何运动，问自己：是不是应该删掉/合并？

## 6. 方向文件模板

复制 `templates/DIRECTION.md`，至少写：

1. 一句话承诺
2. 受众/平台/时长
3. 参考拆解（结构/视觉/声音）
4. 三个方向与选择理由
5. 3–5 个专属手法
6. 视觉规范（数字）
7. 情绪曲线/节拍
8. 镜头表（时间、画面、文案、动作、声音、转场）
9. 风险与替代方案

## 7. 案例

- **绘声绘色 MV**：纸/墨/九色，把“画线→旋律、颜色→音色、扫描→点亮”变成视觉规则；副歌把 UI 变成 3D 纸面海报，避免静态大字。详见 `case-study-drawmusic.md`。
- **知识讲解**：如果主题是“为什么天空是蓝的”，不要用粒子背景；用一束白光穿过棱镜/大气层的图解，颜色在屏幕上被“分离”出来。视觉规则来自主题本身。
- **活动宣传**：如果活动在龙坞茶镇，不要用通用科技蓝；用茶纸/山形/盖章/路线图，把“去现场”变成视觉动词。

## 8. Gate A 检查

- [ ] 一句话承诺能 10 个字说清？
- [ ] 三个方向真的不同轴？
- [ ] 每个专属手法能说出“因为产品/主题有 X”？
- [ ] 视觉规范有具体数字？
- [ ] 镜头表覆盖全时长，且没有连续 3 个静态卡片？
- [ ] 用户看到方向能说“这就是我要的/不是”？
