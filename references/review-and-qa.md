# 审片与 QA

自动检查只能证明“文件/结构/时长/响度”，不能证明“好看/好听/讲清楚”。审片必须人看、人听。

## 1. 三个审片节点

### Gate A：方向/静帧
- 3 个方向 + 3–6 张关键静帧。
- 看：一句话承诺是否成立？视觉是否只属于这个主题？
- 通过后再写全片代码/剪辑。

### Gate B：Animatic/分镜
- 静帧 + 临时音轨，按 `plan.json` 时间播放。
- 看：信息是否来得及？镜头是否太长/太碎？首帧/结尾是否成立？
- 改 plan，不要直接改代码。

### Gate C：Rough cut
- 全片低分辨率/带临时混音。
- 看：节奏、转场、字幕、声音层次。
- 记录问题，一次改一类。

### Gate D：Final
- 全分辨率、最终混音、字幕、封面。
- 跑 `check_delivery.py` + 人工检查。
- 通过后交付。

## 2. 联系表

```sh
python3 <skill-dir>/scripts/contact_sheet.py videos/final.mp4 \
  --out renders/contact.png --fps 1 --cols 6 --width 320
```

看：

- 首帧是否完整？
- 有没有连续 3 个“标题+背景”？
- 颜色/字体是否统一？
- 结尾 CTA 是否停留够？
- 9:16 是否重排过？

## 3. 转场条带

对每个关键转场，抽前后 10 fps：

```sh
ffmpeg -ss 12.0 -i final.mp4 -t 0.8 -vf "fps=10,scale=480:-1,tile=4x2" renders/tr_12.png
```

看：匹配点是否对齐？闪白是否过曝？whip 是否糊成一片？字幕是否被切？

## 4. 全尺寸帧

文字密集/产品 UI/图表镜头，必须看 1920×1080 原帧：

```sh
ffmpeg -ss 8.4 -i final.mp4 -frames:v 1 renders/f_8.4.png
```

检查：字号、对比、错别字、UI 裁切、字幕溢出、二维码可扫。

## 5. 手机/静音

- 把成片放到手机大小（或缩到 25%）看：标题是否可读？主体是否清楚？
- 静音看一遍：信息是否靠字幕/画面成立？
- 手机外放听一遍：人声是否清楚？低频是否消失？
- 在目标平台的安全区里看：字幕是否被 UI 挡住？

## 6. 常见问题

| 现象 | 原因 | 修法 |
|---|---|---|
| 像幻灯片 | 每镜只有标题+背景 | 加相机运动/主体动作/转场；把 bullet 变图解 |
| 首帧空白 | 从入场动画第 0 帧开始 | 首帧放开场完成态，再淡出 |
| 中段很静 | 音乐 loop 无变化/镜头太长 | 加层/break/换镜；每 8–15s 一个变化 |
| 字幕来不及 | 一条太长/太快 | 拆句；12–16 字/行；每条 1.5–4s |
| 字幕被挡 | 没留平台安全区 | 下 15–18% 避开；9:16 重排 |
| 人声糊 | 音乐太响/混响太多 | 音乐 −3–6dB；降混响；EQ 2–5kHz |
| 音效吵 | 每个 cut 都加 | 只留动作/转场关键点；降 3–6dB |
| CTA 记不住 | 结尾太短/信息太多 | 3–5s；只留一个动作+一个 URL/二维码 |
| 产品假 | 用设计稿冒充实机 | 标“概念/原型”；或录真实界面 |
| 竖屏像裁的 | 直接裁 16:9 | 重排：主体居中偏上、字幕下 20%、UI 放大 |

## 7. 自动检查

```sh
python3 <skill-dir>/scripts/check_delivery.py plan.json \
  --video videos/final.mp4 \
  --mix-report audio/mix_report.json \
  --captions videos/final.srt
```

检查项：

- plan 结构：shots 覆盖、id 唯一、action/cue 对应。
- 视频：分辨率/fps/时长/编码/音频流。
- 首帧：ink ratio（不是空白）。
- 黑帧：blackdetect。
- 响度：Integrated/True Peak（有 mix report 则读，否则测）。
- 字幕：SRT 解析、行宽、结束时间。

自动检查通过 ≠ 好看；`QA.md` 必须写人工看/听结论。

## 8. QA 报告

复制 `templates/QA.md`，至少写：

- 自动检查结果（通过/警告/错误）。
- 实际看过的帧/段（时间点）。
- 实际听过的段；耳机/外放。
- 已知残留问题（不影响交付的）。
- 未验证项（例如某平台压缩后的效果）。
- 交付文件 hash/大小/时长。

## 9. 交付前 10 问

1. 一句话承诺成立吗？
2. 首帧能当缩略图吗？
3. 静音能看懂吗？
4. 手机大小能读吗？
5. 每个镜头都在动/有理由吗？
6. 声音有层次吗？人声清楚吗？
7. 结尾 CTA 具体吗？停留够吗？
8. 日期/场地/价格/claims 核对了吗？
9. 版权/字体/音乐/素材有授权吗？
10. 工程能复现吗？别人能按 README 再导一次吗？
